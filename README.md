# Punk Agent

Punk Agent 的 Windows 安装包与版本更新发布页。

## 下载

前往 [Releases](https://github.com/ZCchou/punkagent-releases/releases)，选择最新版本中的 `Punk-Agent-*-windows-x86_64-setup.exe` 安装包。

- 系统：Windows 10/11，64 位（x86_64）。
- 校验：每个版本附带 `SHA256SUMS.txt` 与发布清单。
- 预览版可能尚未签名，具体状态以该版本说明为准。
- 使用模型服务时，请在应用中配置自己的服务或本地模型。

## 关于本仓库

此公开仓库仅存放下载说明、版本说明和二进制发布文件，**不包含 Punk Agent 应用源码**。应用源码在独立的私有仓库中维护。

GitHub 自动生成的 “Source code” 压缩包仅包含本发布仓库的说明文件，不是应用源码。

请从本仓库的 Release 页面下载安装包。不要将 API Key、聊天记录或其他个人数据提交到公开 Issue。
